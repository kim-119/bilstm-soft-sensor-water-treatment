# Bi-LSTM 기반 수처리 공정 Soft Sensor 모델 설계

## 1) 프로젝트 개요

* 본 프로젝트는 수처리 공정에서 발생하는 시계열 센서 데이터를 기반으로 수질 항목을 예측하는 AI 모델 설계 프로젝트이다.
* DO, pH, ORP, 수온, MLSS, 유입 유량, 폭기량, 반송률 등 실시간 공정 데이터를 활용한다.
* 직접 측정이 어렵거나 분석 지연이 발생할 수 있는 NH3-N, COD, BOD, TN 값을 간접 예측하는 Soft Sensor 모델을 목표로 한다.
* 실제 수질 자동제어 시스템이라고 과장하지 않으며, 운영자의 의사결정을 보조하는 예측 모델 수준으로 표현한다.

## 2) 문제 정의

* 수처리 공정은 생물학적 반응, 유입 부하 변화, 수온 변화, 폭기 조건, 슬러지 농도 변화에 따라 비선형적으로 변한다.
* NH3-N, COD, BOD, TN 등의 수질 항목은 방류수질 관리에서 중요하지만 실시간 측정이 어렵거나 분석 지연이 발생할 수 있다.
* 공정 센서 데이터는 실시간으로 수집 가능하므로 이를 활용한 Soft Sensor 모델을 통해 수질 항목을 간접 추정할 수 있다.
* LSTM 계열 모델은 시간 지연성과 누적 효과를 학습하는 데 적합하다.

## 3) Soft Sensor 개념

* Soft Sensor는 직접 측정하기 어렵거나 측정 지연이 있는 값을 다른 센서 변수로부터 추정하는 모델이다.
* 수처리 공정에서는 수질 분석 장비의 한계, 실험실 분석 소요 시간, 측정 주기 지연 문제를 보완하기 위해 사용할 수 있다.
* 본 프로젝트에서는 실시간 공정 센서 데이터를 이용하여 NH3-N, COD, BOD, TN 등을 간접 예측하는 구조로 설명한다.

## 4) Bi-LSTM 선정 이유

* LSTM은 과거 시점의 공정 변화가 현재 또는 미래 수질에 미치는 영향을 학습할 수 있다.
* 수처리 공정은 유입수 변화가 즉시 방류수질에 반영되지 않고 시간 지연을 가진다.
* Bi-LSTM은 정방향과 역방향 시계열 문맥을 함께 학습하여 단방향 LSTM보다 풍부한 시간 패턴을 반영할 수 있다.
* 단, 실시간 온라인 예측에서는 미래 시점 데이터를 사용할 수 없으므로 Bi-LSTM은 오프라인 분석 또는 일정 지연을 허용하는 예측 구조에 적합하다는 한계도 명확히 인식해야 한다.
* 실제 운영 환경에서는 단방향 LSTM, GRU, Temporal CNN, XGBoost 등과의 비교 검토가 필요하다.

## 5) NVIDIA GeForce RTX 3050 사용 조건

* 본 프로젝트는 NVIDIA GeForce RTX 3050 GPU 사용을 전제로 한다.
* 학습 시 CPU가 아니라 CUDA 기반 GPU Acceleration을 우선 사용한다.
* RTX 3050의 VRAM 한계를 고려하여 경량 Bi-LSTM 구조를 사용한다.
* 대형 Transformer, 대형 LLM, 과도한 딥러닝 구조는 사용하지 않는다.
* 기본 batch size는 16으로 설정하고, CUDA out of memory 발생 시 8로 낮춘다.
* hidden size는 64를 기본값으로 사용하고, 필요 시 32 또는 128을 비교한다.
* sequence length는 최근 24시간을 기본으로 하며, 48시간 또는 72시간은 메모리 사용량을 확인한 뒤 확장한다.
* mixed precision 사용이 가능하면 학습 속도와 메모리 효율을 개선할 수 있다.

## 6) 입력 데이터 설명

| 변수    | 설명                  | 수질 예측에서의 의미             |
| ----- | ------------------- | ----------------------- |
| DO    | 용존산소                | 질산화 반응, 폭기 상태와 관련       |
| pH    | 수소이온농도              | 생물학적 처리 효율과 미생물 활성에 영향  |
| ORP   | 산화환원전위              | 질산화/탈질 반응 상태 추정 가능      |
| 수온    | Water Temperature   | 미생물 반응 속도와 처리 효율에 영향    |
| MLSS  | 혼합액 부유고형물           | 활성슬러지 농도 및 생물학적 처리능과 관련 |
| 유입 유량 | Influent Flow Rate  | 체류시간과 부하량 변화에 영향        |
| 폭기량   | Aeration Rate       | DO 제어 및 질산화 반응에 영향      |
| 반송률   | Return Sludge Ratio | 슬러지 농도 유지와 처리 안정성에 영향   |
| 유입 부하 | Influent Load       | COD/TN/NH3-N 변화의 주요 원인  |
| 시간 정보 | Hour, Day, Season   | 계절성, 일변동성, 운전 패턴 반영     |

## 7) 출력 데이터 설명

본 모델의 예측 대상은 다음과 같다.

* NH3-N 예측
* COD 예측
* BOD 예측
* TN 예측
* 방류수질 기준 초과 가능성 추정

예측 구조는 단일 타깃 예측과 다중 타깃 예측으로 구분한다.

* 단일 타깃 예측: 초기 모델은 NH3-N 또는 COD 한 가지 항목만 예측 대상으로 설정하여 구조를 단순화하고 학습 안정성을 확보한다.
* 다중 타깃 예측: 단일 타깃 모델이 안정화된 이후 NH3-N, COD, BOD, TN을 동시에 출력하는 다중 출력 회귀 구조로 확장한다. 이때 항목별 스케일 차이와 손실 가중치 설계를 함께 고려한다.

## 8) 모델 구조

```text
실시간 수처리 센서 데이터
        ↓
결측치 처리 및 이상치 보정
        ↓
정규화 및 시간 단위 리샘플링
        ↓
Sliding Window 시계열 데이터 구성
        ↓
Bi-LSTM Layer
        ↓
Dropout Layer
        ↓
Dense Layer
        ↓
NH3-N / COD / BOD / TN 예측값 출력
```

* 입력 시퀀스 길이는 최근 24시간, 48시간, 72시간 단위로 실험 가능하다.
* 예측 시점은 현재값 추정, 1시간 후 예측, 6시간 후 예측, 24시간 후 예측으로 확장 가능하다.
* 모델은 회귀 문제로 구성한다.
* 손실함수는 MSE 또는 MAE를 사용한다.
* 평가 지표는 MAE, RMSE, R²를 사용한다.

## 9) 데이터 전처리

* Sensor Data Preprocessing: 수처리 센서에서 수집된 원시 데이터를 분석 가능한 형태로 정리한다.
* Missing Value Imputation: 센서 통신 단절이나 점검으로 발생하는 결측치를 보간 또는 제거 규칙에 따라 처리한다.
* Outlier Detection: 센서 오류나 일시적 충격 부하로 발생한 이상치를 통계적 기준(IQR, z-score 등)으로 탐지하고 보정한다.
* Feature Scaling: 변수 간 단위와 범위 차이를 줄이기 위해 스케일링을 적용한다.
* MinMaxScaler: 변수 값을 0~1 범위로 정규화하여 LSTM 학습 안정성을 높인다.
* StandardScaler: 평균 0, 분산 1로 표준화하는 대안으로, 분포 특성에 따라 비교 적용한다.
* 시간 단위 리샘플링: 서로 다른 수집 주기를 가진 센서 데이터를 동일한 시간 간격(예: 1시간)으로 정렬한다.
* Sliding Window 구성: 과거 N시간 구간을 입력으로, 이후 시점을 정답으로 묶어 시계열 학습 샘플을 생성한다.
* 학습/검증/테스트 데이터 분리: 시계열 특성을 보존하기 위해 시간 순서를 기준으로 과거 → 미래 순으로 분리한다.

## 10) 학습 방식

* 시계열 데이터이므로 랜덤 셔플보다 시간 순서 기반 분리를 권장한다.
* Optimizer는 Adam을 사용한다.
* 손실함수는 MSELoss 또는 MAE를 사용한다.
* Early Stopping을 적용하여 검증 손실이 개선되지 않으면 학습을 조기 종료한다.
* Dropout으로 과적합을 완화한다.
* 평가 지표는 MAE, RMSE, R² Score를 사용한다.
* 실제 성능 수치는 데이터 확보 및 학습 이후에 산출하며, 본 문서에서는 임의의 성능 값을 제시하지 않는다.

## 11) 비교 모델

Bi-LSTM 단독 성능을 단정하지 않고, 아래 모델들과 비교하는 실험을 설계한다.

* Linear Regression: 가장 단순한 기준선(baseline)으로, 비선형 모델의 성능 향상 폭을 가늠하는 기준이 된다.
* Random Forest: 비선형 관계와 변수 상호작용을 포착하는 트리 기반 모델로, 시계열 비의존적 기준선 역할을 한다.
* XGBoost: 구조화된 표 형식 데이터에서 강력한 성능을 보이는 부스팅 모델로, 실무에서 자주 쓰이는 강한 기준선이다.
* Vanilla LSTM: 단방향 시계열 모델로, Bi-LSTM의 양방향 구조가 주는 이득을 비교하기 위한 기준이다.
* GRU: LSTM보다 경량인 순환 구조로, RTX 3050 환경에서 속도/메모리 대비 성능을 비교한다.
* Bi-LSTM: 본 프로젝트의 주요 모델로, 양방향 시계열 문맥 학습 효과를 검증한다.

## 12) 기대 효과

* 수질 항목의 실시간 추정 가능
* 측정 지연 보완
* 방류수질 기준 초과 가능성 조기 감지 보조
* 운영자가 폭기량, 반송률, 약품 주입량 등을 조정하는 데 참고 가능
* 수처리 공정 운영 안정성 향상에 기여
* 단, 실제 자동 제어를 보장하지 않으며 의사결정 보조 수준으로 한정한다.

## 13) 한계점

* 실제 현장 데이터 품질에 따라 성능이 크게 달라질 수 있다.
* 센서 결측, 오염, 보정 오류가 모델 성능에 직접적인 영향을 줄 수 있다.
* Bi-LSTM은 내부 동작에 대한 설명 가능성이 낮을 수 있다.
* 실시간 운영 적용 전에는 반드시 현장 검증이 필요하다.
* 데이터가 적으면 과적합 위험이 있다.
* Bi-LSTM의 역방향 구조는 실시간 예측에서 미래 데이터를 사용할 수 없으므로, 데이터 사용 조건과 적용 범위를 명확히 검토해야 한다.
